# 🧩 `09 // PLUGIN ARCHITECTURE`

Freezer-MD uses a modular plugin structure.

```text
plugins/
│
├── ❄️ general/
├── 📥 downloaders/
├── 🧰 tools/
├── 🤖 ai/
├── 🎬 media/
├── 🎮 fun/
├── 👥 group/
├── 🛡️ security/
├── 📊 status/
├── 📢 channel/
├── ⚙️ admin/
└── 👑 owner/
```

### Build your own command

```javascript
const { cmd } = require('../arslan');

cmd({
    pattern: "hello",
    name: "hello",
    category: "General",
    description: "Say hello",
    filename: __filename
}, async (sock, m) => {

    await m.reply(
        `❄️ *FREEZER-MD*\n\n` +
        `Welcome to the Freezer Zone! 🥶`
    );

});
```
