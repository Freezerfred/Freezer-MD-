## ⚡ About Freezer-MD

**Freezer-MD** is a modular WhatsApp automation bot built with **Node.js** and **Baileys**, designed around speed, flexibility and easy plugin development.

The project provides a foundation for building a powerful WhatsApp assistant with a modular command system, media utilities, database support, Express integration and production deployment with PM2.

The current repository contains the core bot system, plugin architecture, session handling and configuration files needed to run Freezer-MD.

# 📦 Installation

## Requirements

Make sure you have:

* Node.js **18 or newer**
* npm
* Git
* WhatsApp account
* Internet connection

---

## 1️⃣ Clone

```bash
git clone https://github.com/Freezerfred/Freezer-MD-.git
cd Freezer-MD-
```

## 2️⃣ Install

```bash
npm install
```

## 3️⃣ Configure

Create/configure your environment variables and bot configuration.

```bash
nano .env
```

Keep all API keys, tokens and session credentials private.

## 4️⃣ Start

```bash
npm start
```

Freezer-MD's repository currently uses `npm start` as its basic startup flow.

# 🧩 Plugin Development

Freezer-MD is built around a modular plugin system.

Plugins are stored inside:

```text
plugins/
```

### Example

```javascript
'use strict';

const { cmd } = require('../arslan');

cmd({
    pattern: 'hello',
    name: 'hello',
    description: 'Say hello',
    category: 'General',
    filename: __filename
}, async (sock, m) => {

    await m.reply('🥶 Hello from Freezer-MD!');

});
```

Save the file inside the plugins directory and restart the bot.

# 🚀 Production Deployment

For production environments, **VPS + Node.js + PM2** is recommended.

### Install PM2

```bash
npm install -g pm2
```

### Start Freezer-MD

```bash
pm2 start index.js --name Freezer-MD
```

### Save process

```bash
pm2 save
```

### Enable startup

```bash
pm2 startup
```

### View logs

```bash
pm2 logs Freezer-MD
```

### Restart

```bash
pm2 restart Freezer-MD
```

### Stop

```bash
pm2 stop Freezer-MD
```

Security matters.

```text

.env
session/
auth/
*.log
```
