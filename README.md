# 🧩 `PLUGIN ARCHITECTURE`

Freezer-MD is built around a **clean modular plugin system**.

```text
plugins/
│
├── ❄️ general/
├── 📥 downloaders/
├── 🧰 tools/
├── 🤖 ai/
├── 🎬 media/
├── 🎮 fun/
├── 👥 group/
├── 🛡️ security/
├── 📊 status/
├── 📢 channel/
├── ⚙️ admin/
└── 👑 owner/
```

### Want a new command?

Create a plugin.

```javascript
const { cmd } = require('../arslan');

cmd({
    pattern: "hello",
    name: "hello",
    category: "General",
    description: "Say hello",
    filename: __filename
}, async (sock, m) => {

    await m.reply(
        `❄️ *FREEZER-MD*\n\n` +
        `Welcome to the Freezer zone! 🥶`
    );

});
```

**Simple. Clean. Powerful.**
